# Reinforcement Learning Lab

A collection of Reinforcement Learning laboratory experiments implemented using Python and Gymnasium.

## Projects

| No. | Project | Technique | Status |
|---|---|---|---|
| 01 | [Mountain Car – Random Agent](Project-01-Mountain-Car/) | Random action selection | Completed |
| 02 | Frozen Lake | Q-Learning | Planned |
| 03 | Taxi-v3 | Q-Learning | Planned |
| 04 | Taxi-v3 | SARSA vs Q-Learning | Planned |

## Requirements

- Python 3.9 or later
- Gymnasium
- NumPy
- Matplotlib (for notebook-based visualizations)

Install the dependencies:

```bash
pip install -r requirements.txt
```

## Running a project

Open the relevant project folder and follow its README. For example:

```bash
cd Project-01-Mountain-Car
pip install -r requirements.txt
python mountain_car_random_agent.py
```

## About

This repository is maintained as a learning record for Reinforcement Learning concepts, environments, algorithms, experiments, and observations.
